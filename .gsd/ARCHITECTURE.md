# Architecture

> Generated by /map on 2026-10-19

## Overview

Expenso is structured as a full-stack Next.js App Router application with strict boundaries between presentation, server actions / API endpoints, domain logic (financial calculations in integer paise), and MongoDB persistence via Mongoose and Better Auth.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       CLIENT TIER (Next.js App)                         │
│  - Responsive Shell (Desktop Sidebar + Mobile Bottom Nav)               │
│  - Financial Dashboards & Data Tables (shadcn/ui + Tailwind v4)         │
│  - Form & Validation Layer (Zod + React Hook Form)                      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    API & SERVER ACTIONS LAYER                           │
│  - Better Auth Handler (`/api/auth/[...all]`)                           │
│  - Authenticated Server Actions & Route Handlers                        │
│  - Strict Session & Ownership Guard                                     │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    DOMAIN / BUSINESS LOGIC LAYER                        │
│  - Integer Paise Financial Calculator & Currency Formatter              │
│  - Account Reconciliation & Transfer Invariance Engine                  │
│  - Category & Audit Trail Reducers                                      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    PERSISTENCE TIER (MongoDB)                           │
│  - Better Auth Collections (User, Session, Account, Verification)       │
│  - Financial Models (BankAccount, Transaction, LoanDebt, Investment)    │
│  - Audit Log & Snapshot Collections                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

## Directory Structure

```
expenso/
├── app/
│   ├── (auth)/                  # Auth routes (login, register)
│   ├── (dashboard)/             # Protected app routes (dashboard, accounts, transactions, etc.)
│   ├── api/
│   │   └── auth/[...all]/       # Better Auth API endpoint
│   ├── globals.css              # Custom design tokens & Tailwind imports
│   └── layout.tsx               # Root layout & font injection
├── components/
│   ├── layout/                  # Shell: Sidebar, BottomNav, Header, UserMenu
│   ├── ui/                      # Reusable shadcn/ui components
│   └── dashboard/               # Feature-specific dashboard cards
├── lib/
│   ├── auth/                    # Better Auth server and client configurations
│   ├── db/                      # MongoDB client & Mongoose connection caching
│   ├── models/                  # Mongoose models (User, BankAccount, Transaction, etc.)
│   ├── utils/                   # Formatting (INR, dates), cn utility, validators
│   └── constants/               # Color tokens, nav items, categories
```

## Conventions

- **State & Rendering**: Server Components for data fetching by default. Client Components (`"use client"`) only for interactive inputs, forms, and mobile responsive menus.
- **Financial Calculations**: Pure TypeScript functions in `lib/utils/currency.ts` taking and returning integer paise (`amountInPaise`). No floating-point math in financial totals.
- **Security**: All database operations query `{ userId: session.user.id }`. No client-supplied user identifiers are trusted.
